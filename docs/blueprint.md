# **App Name**: 字裡乾坤

## Core Features:

- 文字輸入: 提供一個文字輸入框，讓使用者輸入想要測的字。
- 文字儲存: 將使用者輸入的文字儲存起來，以供後續分析使用。
- AI 測字分析: 利用 AI 模型分析文字的結構、筆劃等，並根據傳統的測字理論，產生多個可能的解釋和建議。
- 結果呈現: 以易於閱讀的方式呈現 AI 分析的結果，包括文字的各個面向、可能的運勢走向、以及建議。
- AI 產生鼓勵語句: 使用 AI tool產生與分析結果相關的正面鼓勵語句，讓使用者在測字後感到有所啟發。

## Style Guidelines:

- 主色調：採用溫暖的米色或淺棕色，營造傳統文化的氛圍。
- 輔助色調：使用沉穩的墨綠色或深藍色，增加專業感和信任感。
- 強調色：使用硃紅色 (#D43A3A) 作為重點提示和按鈕的顏色。
- 採用傳統明體或宋體，呈現古典風格。
- 使用簡約的線條風格圖示，例如毛筆、硯台、八卦等，增添文化氣息。
- 整體版面採用簡潔、對稱的設計，避免過多裝飾，著重內容的呈現。
- 加入適度的過場動畫，例如文字淡入淡出、圖示緩慢旋轉等，增加互動性。

## Original User Request:
寫一個網頁版的測字占卜程式
全程使用台灣繁體中文，包括用語、習慣
